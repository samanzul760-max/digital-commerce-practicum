学生端 API

学生端不是静态课程展示，也不是自由开店工具。它是受教学任务驱动的学习记录系统：学生在被分配的任务中学习、练习、保存过程证据、提交成果、接收反馈，并从真实数据了解自己的成长。

学生学习能力全景

首页与待办可做任务、退回任务、截止提醒、最近反馈、学习日历和个人完成摘要。
课程与资源已发布计划、学习目录、教学资料、软件、训练营、企业案例和受控应用入口。
实训与答题任务指南、阅读进度、题目尝试、倒计时、五类沙盘、步骤检查和证据保存。
提交与重做草稿、附件、链接、沙盘快照、不可变提交版本、退回修改和重新提交。
反馈与成长自动分、人工分、评语、评分明细、完成率、技能图谱、计划钻取和趋势。
通知与赛考任务/评分/公告提醒，资格内赛考报名、参赛提交与个人结果。

一次成熟的学生学习流程

1. 收到任务：首页只显示该学生被发布且当前可用的 StudentTask；依赖未完成时明确显示锁定原因。
2. 学习与实践：任务详情来自发布快照，学生阅读要求、观看媒体、答题、进入沙盘，并随时保存草稿和证据。
3. 提交：服务器检查时限、状态、依赖和必做项；成功后创建不可变版本并进入待批阅。
4. 反馈：退回后学生看到对应版本的原因，完成修改再提交新版本；评分后查看本人分数和评语。
5. 成长：个人数据由真实任务、提交和评分聚合，可追溯到具体任务与版本。
LOCKED -> AVAILABLE -> IN_PROGRESS -> SUBMITTED
SUBMITTED -> RETURNED -> SUBMITTED -> GRADED

功能细则

功能学生看到什么服务端必须保证
任务首页待办、进行中、退回、已完成、截止时间和最近反馈。只读本人任务；没有任务返回真实空状态，不能伪造统计数字。
学习目录目标、步骤、媒体、前置条件、时限和完成标准。来自冻结快照；不返回答案、教师备注或其他学生信息。
资源/应用已授权的课程、资料、软件、训练和案例。每次访问再次校验实训室、班级和可见范围。
学习过程可恢复的阅读位置、完成步骤、保存状态。事件和草稿持久化；刷新或换设备后仍可恢复。
沙盘店铺、商品、装修、营销、经营分析等受控练习。每个会话绑定 studentTaskId；不能碰到真实商家或他人沙盘。
答题练习题目、剩余次数、时限和允许看到的结果。服务端校验题目结构、次数、时间和自动判分；答案密钥不下发。
提交版本文本、附件、链接、证据、提交时间和版本历史。幂等提交；不允许修改已提交版本；缺项要给出安全定位提示。
成绩反馈本人自动/人工/总分、评语、退回原因和版本关系。只能读取本人已释放成绩；不泄露教师私有备注或同学成绩。
个人数据完成率、技能、趋势、计划与任务钻取。从真实记录聚合；没有数据时明确为空，不用演示图表冒充。
赛考可报名赛事、个人任务、提交和已发布的个人结果。资格、开放时间和结果发布状态均由服务端检查。

正式 API 结构

/api/center/overview                 首页摘要、待办、日历
/api/center/plans/*                  已发布学习计划和目录
/api/center/resources, /applications 资源与应用中心
/api/center/assignments              本人任务列表
/api/center/student-tasks/:id/*      开始、事件、草稿、沙盘、答题、提交
/api/center/submissions/:id          本人提交版本、反馈与成绩
/api/center/data/*                   个人进度、技能、计划钻取
/api/center/notifications/*          通知与已读状态
/api/center/competitions/*           资格内赛考参与和个人结果

验收门槛

学生端要证明真实学习闭环：学生只能看到自己的已发布任务；能保存草稿和沙盘证据；缺项不能提交；退回后产生新版本；评分后能看到本人反馈和个人数据；同时任何跨学生、跨班级、未发布内容或答案密钥请求都必须被服务器拒绝。

公开调研补充：成熟学生学习记录

知识与资源学生在授权范围内读取课程大纲、任务书、知识库、视频、课件、案例和题库，并回到对应任务继续学习。
状态可见必须清楚区分锁定、可做、进行中、已提交、退回、已批阅和关闭；状态来自服务端。
场景实训店铺、数据运营、客服、跨境、直播等都是任务绑定的受控场景，过程证据可恢复、可批阅。
结果与成长学生只看到自己的尝试、反馈、版本、分数和学习轨迹；班级比较须由实训室政策明确开启。
通知闭环任务、公告、截止、退回、评分和符合资格的赛考通知都要有真实记录，打开后再次核验权限。

公开来源：西昌学院、跨境电子商务专业实训室采购要求、上海工商职业技术学院直播电商采购要求、深圳大学。

学生端对标验收

入口完整首页待办、资源任务、受控实训、提交反馈、个人数据、通知和赛考都有清晰入口。
真实学习任务、进度、草稿、尝试、沙盘快照和提交版本均来自持久化数据，可跨会话恢复。
真实结果学生只看到已发布的个人成绩、反馈和成长数据，退回后才能形成新版本。
安全边界不能用 URL、浏览器状态或通知访问他人数据、答案密钥和教师私有备注。
验收证据每项都有学生归属验证、异常状态测试、真实数据浏览器路径和 390px 无溢出检查。
