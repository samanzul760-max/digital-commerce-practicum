LearnEC / 后端任务包 02

管理员 / 教师端 API

一个成熟电商教学平台的管理端，不只是“创建任务”。它要能管理学生与班级、组织教学内容、发放受控实训、组织课堂、批阅成果、分析学情、管理赛考，并对每个高风险操作留痕。

管理员端能力全景

人员与班级学生账号、导入、启停、重置密码、届别、班级、成员、虚拟分组、邀请和申请审批。
内容与资源软件、课程、训练营、企业任务、媒体附件、标签、可见范围、引用关系和模板复用。
任务与课堂工单模板、题目、沙盘、量规、依赖、发布、关闭、课堂作业、公告和授课会话。
批阅与质量提交队列、证据时间线、版本比较、自动/人工加权、退回、评分修订和审计。
学情与导出完成率、迟交、平均分、任务分析、学生钻取、技能数据、成绩单与操作审计。
赛考管理题库、赛考模板、报名范围、开放窗口、结果发布、关闭归档和防泄漏。

从资源到成绩的教学闭环

资源治理：管理员把可用的软件、训练、资料和媒体纳入目录，设置标签和可见范围。被模板引用的资源不能无提示删除。
组建工单：从资源生成模板，配置学习区块、题目、五类沙盘、必做证据、依赖关系、时限和评分权重。
发布：选择班级或分组、时间窗口和规则；服务器生成冻结快照和每位学生的独立任务。
课堂：围绕已发布任务发送公告、建立课堂会话、查看参与和未提交情况，不创建第二套作业表。
批阅：查看真实证据和提交版本，评分或退回；分数、评语、修订、通知和审计一起持久化。
数据：按班级、任务、分组和学生聚合真实记录，生成可追溯的 Excel 导出。

关键功能细则

功能必须做到后端保护
账号管理单个/批量创建学生、行级错误报告、账号启停、临时密码重置。密码仅哈希保存；停用立即撤销会话；所有动作审计。
成员与分组搜索、分页、分组、邀请、申请、单个或批量审批。活跃班级成员唯一；邀请可过期、撤销；不能按显示名合并人员。
媒体资源文件上传、预览、替换、引用检查、可见范围控制。校验扩展名、MIME、大小和存储键；不返回真实本地路径。
任务编辑草稿版本、区块排序、题目、沙盘、量规、依赖、学生预览。权重合计 100；依赖无环；预览隐藏答案和内部备注。
任务发布班级/分组范围、开始结束时间、时限、撤回和关闭。幂等发布；事务创建 StudentTask；发布后冻结学生快照。
批阅评分筛选队列、证据时间线、评分修改、退回重做、下一位学生。expectedVersion 防旧页面评分；退回必须评语；追加评分修订。
数据导出班级总览、排名、任务分析、学生钻取、成绩表下载。服务器生成文件；字段固定且记录导出审计。
赛考题库、范围、报名、时限、结果发布和关闭。复用任务/提交/评分；未发布结果不对学生可见。

正式 API 结构

/api/admin/accounts/*             学生账号与状态
/api/admin/classes/*              班级、成员、分组、邀请、申请
/api/admin/resources/*            资源目录与媒体
/api/admin/task-templates/*       工单模板与复制
/api/admin/tasks/*                编辑、预览、发布、关闭
/api/admin/classes/:id/*          公告、课堂会话、执行记录
/api/admin/reviews/*              队列、证据、评分、退回
/api/admin/data/*                 数据、导出、审计
/api/admin/competitions/*         题库、赛考、结果

验收门槛

不是接口能返回 200 就算完成。管理员端必须能在隔离数据库中：创建班级并加入学生 -> 创建完整工单 -> 发布 -> 收到学生真实提交 -> 批阅/退回/修订评分 -> 导出正确成绩；同时学生和其他实训室管理员的越权请求必须被服务端拒绝。

公开调研补充：成熟教学运营

课程与任务书管理员维护目标、前置知识、步骤、题目、资源、量规和场景包；发布后生成学生安全快照。
课堂编排开设课堂、关联已发布任务、发布公告、布置作业或测验，并从同一任务链读取参与和进度。
过程评价批阅时可查看事件、草稿、尝试、快照、耗时和提交版本，而不是只看最终分数。
评分与干预自动评分和人工量规合并计算；教师可钻取迟交、错误模式、分布和任务证据，导出操作有审计。
专业模块跨境、数据、客服、直播作为资源/规则/量规包接入，统一复用提交、成绩和权限。

公开来源：西昌学院、跨境电子商务专业实训室采购要求、上海工商职业技术学院直播电商采购要求、深圳大学。

管理端对标验收

入口完整人员班级、资源任务、课堂、批阅、数据、赛考均有明确入口和空态。
真实课堂公告、授课、作业和考试复用已发布任务，不产生第二套作业数据。
真实批阅教师看得到过程证据、版本和量规，支持评分、退回、修订、通知和审计。
真实数据班级/任务/学生数据均可回钻，导出由服务端生成并记录审计。
验收证据每项都有权限测试、错误路径、真实 Prisma 数据浏览器流程和移动端检查。
