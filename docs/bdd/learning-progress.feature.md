# Learning Progress BDD

## SB-PLAN-002 Dependency unlock

```gherkin
场景: 学生不能提交未满足前置条件的任务
  假如 学生的任务 B 依赖尚未完成的任务 A
  当 学生提交任务 B
  那么 服务端返回任务锁定冲突且任务 B 保持 LOCKED

场景: 前置任务完成后解锁后置任务
  假如 学生的任务 B 依赖已经完成的任务 A
  当 学生读取任务 B
  那么 服务端将任务 B 标记为 AVAILABLE

场景: 教师评分前置任务后解锁后置任务
  假如 学生的任务 B 依赖已经提交的任务 A
  当 教师为任务 A 完成评分
  那么 服务端将任务 B 标记为 AVAILABLE
```

## C-STUDENT-001 至 C-STUDENT-006 学生真实任务闭环

```gherkin
场景: 学生只能看到自己被分配的服务端任务
  假如 教师已在当前实训室创建班级并向学生分配一个已发布任务
  当 学生登录并打开任务页
  那么 页面显示任务类型、标题、来源、发布时间、截止时间和状态
  并且 刷新页面后任务仍然存在
  并且 学生看不到其他学生的任务

场景: 学生提交任务后生成服务端版本
  假如 学生拥有一个 AVAILABLE 状态的任务
  当 学生输入非空成果并确认提交
  那么 页面显示 SUBMITTED 状态
  并且 服务端保存一个不可变版本
  并且 重复使用同一个幂等键不会产生第二个版本

场景: 学生不能提交非法任务
  假如 学生的任务为 LOCKED、CLOSED 或 GRADED 状态
  当 学生尝试提交
  那么 页面显示明确的状态错误
  并且 服务端拒绝请求且不创建新版本

场景: 学生处理教师退回
  假如 教师已对学生的 SUBMITTED 任务填写反馈并退回
  当 学生刷新任务详情并修改成果后再次提交
  那么 页面显示新版本和原版本
  并且 原版本内容保持不变

场景: 学生查看评分结果
  假如 教师已对学生提交按评分规则完成评分
  当 学生刷新任务详情
  那么 页面显示总分、分项结果、反馈和评分时间
  并且 学生不能修改教师评分
```

## C-STUDENT-007 至 C-STUDENT-010 服务端学习合同

### C-STUDENT-007 保存草稿并在刷新后恢复

```gherkin
场景: 学生保存任务草稿
  假如 学生拥有状态为 AVAILABLE 的服务端任务
  当 学生保存非空草稿但尚未提交
  那么 服务端返回草稿内容和更新时间
  并且 学生刷新任务详情后仍能看到同一份草稿
```

### C-STUDENT-008 拒绝空提交

```gherkin
场景: 学生不能提交空结果
  假如 学生拥有状态为 AVAILABLE 的服务端任务
  当 学生提交空白或仅包含空格的结果
  那么 服务端返回 422/SUBMISSION_INVALID
  并且 不创建提交版本且任务仍保持 AVAILABLE
```

### C-STUDENT-009 退回后再次提交并保留版本

```gherkin
场景: 学生处理教师退回
  假如 教师已将学生的 SUBMITTED 任务退回并写入反馈
  当 学生修改结果后再次提交
  那么 服务端创建递增的新版本并将任务置为 SUBMITTED
  并且 原版本内容和教师反馈仍可查看
```

### C-STUDENT-010 越权读取被拒绝

```gherkin
场景: 学生不能读取其他学生的任务
  假如 任务属于另一名学生或另一间无授权的实训室
  当 当前学生读取任务详情或提交结果
  那么 服务端返回 404/TASK_NOT_FOUND 或明确的权限错误
  并且 不返回其他学生的提交、评分或反馈数据
```

## SB-SUB-002 Idempotency

```gherkin
场景: 重复的提交请求不会创建新的版本
  假如 学生有一项可提交的任务
  当 学生使用相同的 Idempotency-Key 重复提交
  那么 服务端返回首次提交结果且只保留一个提交版本
```
