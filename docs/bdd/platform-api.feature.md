# 平台横向 API BDD

## 资源与成员

Given 管理员已经登录
When 管理员查询、创建、修改或移除资源和成员
Then 服务端执行分页、校验、权限和持久化

Given 学生已经登录
When 学生请求管理资源或成员接口
Then 服务端返回专用 forbidden 错误，不返回数据

## 通知与统计

Given 用户已经登录
When 用户查询通知或统计
Then 只能返回当前用户角色和实训室范围内的数据
And 标记已读后刷新仍保持已读

## 文件上传

Given 管理员选择一个文件
When 文件类型或大小不符合上传策略
Then 服务端拒绝写入并返回明确错误码
When 文件符合策略
Then 服务端只保存安全文件名和元数据，不暴露本地路径
