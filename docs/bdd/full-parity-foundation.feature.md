# 全量对标基础能力

## SB-Q-10: 受保护写请求的跨站请求防护

场景: 已登录用户缺少 CSRF 令牌时不能修改实训室数据

假如 OWNER 已通过 HttpOnly session 登录
当 浏览器向计划、成员、资源、提交或评分的写入接口发送请求但没有有效 CSRF 令牌
那么 服务端返回稳定的 `403 CSRF_INVALID`
并且 不创建或修改任何业务数据

场景: 已登录用户携带当前会话的 CSRF 令牌时可以执行已授权写操作

假如 OWNER 已通过 HttpOnly session 登录并获得当前会话的 CSRF 令牌
当 浏览器携带该令牌创建计划
那么 服务端按既有角色、实训室、幂等和校验规则处理请求
并且 令牌不出现在 API 响应、日志或页面文本中

## SB-G-02 / SB-G-03：组织与实训室上下文

场景：有多个组织权限的用户选择工作空间

假如用户已登录且拥有多个组织的成员资格
当用户在组织选择器选择一个组织和其下的实训室
那么顶栏显示所选组织和实训室
并且后续计划、成员、资源和统计只查询该实训室
并且刷新页面后仍保持当前上下文

场景：用户尝试直接访问未授权实训室

假如用户不属于目标实训室
当用户直接请求该实训室的 API 或页面
那么服务器返回稳定的无权限错误
并且页面不显示任何目标实训室字段

## SB-Q-03 / SB-Q-04：教师角色和三层授权

场景：教师管理教学但不能越过实训室边界

假如教师属于当前实训室
当教师创建课堂作业或公告
那么操作成功且仅在当前实训室保存
并且教师不能修改组织范围或其他实训室的数据

场景：学生直接访问教师页面

假如学生已登录
当学生直接访问教师路由或调用教师写入 API
那么页面显示无权限状态且 API 返回 403
并且不返回作业、公告或成员数据
功能: 组织、实训室与角色上下文

  场景: [SB-G-02][SB-G-03][SB-G-04] 已登录用户读取当前工作上下文
    假如 管理员属于演示组织且被授予数字商贸实训室的访问权限
    当 管理员请求当前工作上下文
    那么 返回当前组织、当前实训室、教学模式和管理员角色
    并且 返回的实训室属于该管理员可访问的实训室列表

  场景: [SB-G-02][SB-Q-02][SB-Q-03] 教师只能读取自己的上下文
    假如 教师属于演示组织且只被授予数字商贸实训室的访问权限
    当 教师请求当前工作上下文
    那么 返回教师角色和被授权的实训室
    并且 不返回管理员专属权限或未授权实训室

  场景: [SB-G-03][SB-Q-01] 切换组织上下文后刷新仍然保留选择
    假如 管理员拥有多个组织的访问权限
    当 管理员选择一个已授权组织和实训室
    那么 服务端把选择保存到当前会话
    并且 刷新后当前工作上下文保持该选择
