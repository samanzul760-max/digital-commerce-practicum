# 全量对标基础能力

## SB-G-02 / SB-G-03：组织与实训室上下文

场景：有多个组织权限的用户选择工作空间

假如用户已登录且拥有多个组织的成员资格
当用户在组织选择器选择一个组织和其下的实训室
那么顶栏显示所选组织和实训室
并且后续计划、成员、资源和统计只查询该实训室
并且刷新页面后仍保持当前上下文

场景：用户尝试直接访问未授权实训室

假如用户不属于目标实训室
当用户直接请求该实训室的 API 或页面
那么服务器返回稳定的无权限错误
并且页面不显示任何目标实训室字段

## SB-Q-03 / SB-Q-04：教师角色和三层授权

场景：教师管理教学但不能越过实训室边界

假如教师属于当前实训室
当教师创建课堂作业或公告
那么操作成功且仅在当前实训室保存
并且教师不能修改组织范围或其他实训室的数据

场景：学生直接访问教师页面

假如学生已登录
当学生直接访问教师路由或调用教师写入 API
那么页面显示无权限状态且 API 返回 403
并且不返回作业、公告或成员数据
