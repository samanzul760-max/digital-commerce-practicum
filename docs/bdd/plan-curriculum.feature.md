# language: zh-CN
功能: 阶段 B 综合工单组课与发布
  为了形成“管理员发任务、学生获得独立任务实例”的教学闭环
  作为 ADMIN
  我需要从真实资源库编排工单、保存模板并幂等发布给授权班级

  背景:
    假如系统只有 ADMIN 与 STUDENT 两个新角色
    并且资源、工单、模板和学生任务均保存于 Prisma/PostgreSQL

  场景: ADMIN 从三类资源库创建综合工单
    假如 ADMIN 已登录并拥有目标班级权限
    当 ADMIN 从软件中心、技能训练营和企业任务库选择活动
    并且将实操与客观题区块权重设置为 70 和 30
    那么刷新页面后仍能从服务端读取工单及有序区块

  场景: 非法工单被服务端拒绝
    假如 ADMIN 已登录
    当 ADMIN 提交空标题、无权班级或合计不为 100 的评分权重
    那么服务端分别返回稳定的 422 或 404 错误
    并且不创建伪成功的工单或学生任务

  场景: 学生预览不泄露答案键
    假如 ADMIN 已保存含客观题答案的草稿
    当 ADMIN 打开学生视角预览
    那么预览包含题干与选项
    但是响应不包含 answerKey 和教师内部解析

  场景: 模板复制产生独立草稿
    假如 ADMIN 已把工单保存为模板
    当 ADMIN 一键复制模板到授权班级
    那么系统创建新的 DRAFT 工单和独立区块记录
    并且后续编辑副本不改变原工单与模板

  场景: 发布为每名有效学生生成一个任务实例
    假如班级有一名有效 STUDENT
    并且综合工单的总权重和区块权重均为 100
    当 ADMIN 使用幂等键发布工单两次
    那么工单状态为 PUBLISHED
    并且该学生只有一条 StudentTask
    并且发布快照冻结题目、沙盘步骤和评分权重

  场景: STUDENT 无法访问管理端工单接口
    假如 STUDENT 已登录
    当 STUDENT 访问资源库、工单或分类实训中心接口
    那么服务端返回 403

  场景: 分类实训中心诚实展示能力状态
    假如 ADMIN 已登录
    当 ADMIN 打开公共实训中心
    那么页面展示教学、比赛和考证三类入口
    并且比赛与考证显示 COMING_SOON
    但是系统不创建虚假参赛名单或成绩
