# Slice 4 OWNER 审核 PRD

Feature ID：`ASSUME-S4-001`

产品仅有 `OWNER` 和 `STUDENT`。`OWNER` 是唯一审核者；所有旧四角色措辞按此权限模型规范化，不新增其他身份、路由或隐藏权限。

| 编号 | 行为 | 完成条件 |
|---|---|---|
| S4-01 | OWNER 查看审核队列 | 显示学生、计划、单元、活动、版本、时间、状态 |
| S4-02 | 筛选与排序 | 按计划、单元、状态、学生筛选；按最早/最新提交排序 |
| S4-03 | 退回修改 | 反馈必填；确认后状态为 `RETURNED` 并持久化 |
| S4-04 | 学生修订历史 | 学生从 `RETURNED` 再提交，旧版本与反馈不可变 |
| S4-05 | 量规完整性 | 任一必评维度缺失时阻止最终评分并指出缺失项 |
| S4-06 | 最终评分证据 | 保存审核者、时间、量规分值、反馈和 `GRADED` 状态 |
| S4-07 | 两角色越权边界 | 学生不能进入审核页、退回或评分；产品不暴露第三种审核身份 |
| S4-08 | 审核中心视图保持 | 计划/课堂、待处理/已处理切换后筛选不丢失 |
| S4-09 | 统一详情入口 | 首页快捷审核和计划入口打开同一授权详情契约 |
| S4-10 | 完整状态 | 首页、队列、详情覆盖 loading、empty-filter、forbidden、returned、graded、immutable-history |

提交版本、审核反馈与最终评分是持久化证据。最终评分不可覆盖；原型不提供批量审核、重开或替换评分。
