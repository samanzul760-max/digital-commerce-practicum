04 · Implementation Flow

四步实施流程

每个模块按相同流程接入：数据源 → UI面板 → 交互 → 验证。

1

接入数据源

在现有 usePracticumServer 中确认 API 方法可用

  • server.listProducts()
  • server.listStudentTasks()
  • server.listCases()
  • server.listNotifications()
2

创建 UI 面板

在对应页面内新增 v-show 面板，复用现有 CSS 变量和组件风格

  • 完全沿用设计稿 CSS
  • 复用 paper/table/pill 等类
  • 保持轻蓝工作台风格
3

连接交互

用 Vue 响应式绑定数据，添加加载态/空态/错误态

  • ref + computed 响应式
  • 并行 API 调用
  • router.push 客户端导航
4

验证闭环

确保角色切换后数据刷新，下拉菜单联动，外链正确

  • 学员 ↔ 管理切换刷新
  • 通知铃铛联动
  • typecheck + build 通过
