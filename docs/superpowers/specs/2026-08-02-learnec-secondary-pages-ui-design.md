# LearnEC 二级页面 UI 统一设计

## 目标

将成员管理、管理员班级能力画像、任务权限提示和学生待办页统一到 LearnEC 的轻量工作台设计语言，同时保持现有业务逻辑、权限规则和数据来源不变。

## 设计系统

- 主色使用 `#147bd1`，页面背景使用 `#f4f7f8`，卡片背景使用白色。
- 主文本使用 `#17222e`，副文本使用 `#697786`，边框使用 `#e9edf0`。
- 数据容器统一使用 `.paper`：白底、1px 边框、6px 圆角、`16px 20px` 内边距。
- 主按钮统一使用 `.blue-btn`/`.primary-button`；次按钮统一使用 `.secondary-button`/`.ghost-button`。
- 输入框和下拉框高度统一为 32px，使用 4px 圆角与蓝色 Focus 边框。
- 空状态使用居中卡片、图标、标题、说明和明确操作，不使用虚线框。

## 页面调整

### 成员管理

成员行使用平滑边框列表并在窄屏堆叠。成员名称和角色信息保持在左侧，分组输入与三个操作按钮形成紧凑操作区。虚拟分组概览使用 `.paper` 卡片。

### 班级能力画像

四项关键指标各自使用 `.paper`。雷达图放在带标题的 `.paper` 容器内，扩大 viewBox 与标签半径，按标签所在方位设置锚点，短标签直接显示，完整文本通过 SVG `title` 和右侧图例提供。

### 权限提示

管理员打开学生任务页时显示居中的 `.paper` 空状态，使用切换视角图标、清晰标题和说明，并提供“切换至学生视角”蓝色按钮。按钮直接更新现有工作区角色状态。

### 我的任务

四个统计指标使用统一 `.paper` 质感。待办列表保持扫描友好的分隔列表，所有右侧操作统一为 `.blue-btn`，移动端改为整行按钮并避免水平溢出。
