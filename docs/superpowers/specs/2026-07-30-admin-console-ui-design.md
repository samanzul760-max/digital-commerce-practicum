# 管理员控制台 UI 重构设计

## 目标

重构管理员控制台的视觉层，使其与登录页、学员中心共享同一套深海蓝、活力橙、浅灰白工作台语言。保留现有认证、角色权限、计划创建、课程编辑、审核、成员、案例、数据中心和资源中心的路由及业务行为。

## 范围与非范围

范围包括：管理员首页、共享侧边栏、共享顶部栏和登录前入口的视觉一致性。

不改动：认证接口、角色授权、数据模型、计划/审核 API、URL 结构和提交状态机。没有历史数据来源的增长率不伪造；指标使用“实时数据”或现有状态标签。

## 体验结构

1. 未登录访问任意工作台页继续重定向至 `/practicum/login`。登录端为进入产品前的独立体验，不出现在已登录工作台的导航中。
2. 管理员在 `/practicum` 看到运营总览：标题与主操作、四个实时指标、课程管理表格、快速审核和最新实操动态。
3. 侧边栏保留五个真实一级入口：总览、教学、案例、教学管理、数据。通知只保留在顶部铃铛中。
4. 管理员与学员通过已有的角色切换能力进入各自工作台；登录退出保留在个人菜单，避免在侧边栏放置会误退出的入口。

## 视觉令牌

- 页面底色：`#F5F7FA`；内容卡片：`#FFFFFF`；主文字：`#1E293B`。
- 品牌主色：`#1890FF`；强调色：`#FA8C16`；成功色：既有绿色令牌。
- 所有容器、卡片、输入、按钮、选中导航：`14px` 圆角。
- 间距使用 `8px` 基准：组件内部 16px/24px，区块间 24px/32px。
- 使用低对比度环境阴影区分层级，避免纯黑或纯灰描边；只有需要分隔表格信息时使用柔和分隔线。

## 组件设计

### 侧边栏

深海蓝背景上的品牌文字与轻量图标组合，移除独立的实心蓝色 Logo 方块。当前导航使用半透明浅蓝底、14px 圆角和细微亮色指示条；未选中项保持低对比文字和简洁悬停态。

### 顶部栏

顶部仅保留页面标题、简短上下文、通知铃铛和个人菜单。个人菜单继续提供账号权限、成员管理、实训室设置和角色切换等真实低频操作。

### 数据指标

四项指标显示真实的计划数、审核数、完成率和活动数。每项使用白色卡片、淡色圆形图标容器、深色数值和语义化的小标签；不使用波浪线或伪造趋势图。

### 课程管理与审核

课程列表使用白色大卡片、16px 以上的行内舒适间距、状态胶囊和现有“管理”操作。审核模块改成白底、浅橙提示区域和橙色数量，保留跳转到现有提交审核详情的能力。

### 最新实操动态

使用已有提交/审核队列数据渲染学员、活动名、时间和状态；无数据时显示明确空状态，不虚构动态。

## 响应式与可访问性

桌面端为指标四列和主辅两栏。窄屏时指标、表格和侧栏按单列或双列收排；不产生横向溢出。保留现有键盘焦点、ARIA 标签、导航语义和通知菜单行为。

## 验收

1. 未登录访问工作台仍前往登录端。
2. 管理员保留新建计划、课程管理、进入审核、成员/案例/数据中心入口。
3. 学员角色不获得管理员导航或管理操作。
4. 所有管理员可见容器采用 14px 圆角和 8px 间距节奏。
5. 管理员首页在桌面和移动尺寸无水平溢出。
6. 现有认证、角色和管理员首页相关 Playwright 测试通过，外加针对新管理员首页可见性和真实跳转的覆盖。
