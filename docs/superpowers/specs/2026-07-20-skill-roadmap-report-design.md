# 数字商贸实训工作台 Skill 路线图交付件设计

## 目标

生成一个位于桌面的自包含 HTML，用通俗中文说明总控 Skill、Slice 1-6 的职责、预期页面和最终交付状态。

## 结构

- 顶部总览：项目目标、7 个 Skill、4 个角色、主要页面和固定开发流程。
- 总控 Skill：边界、顺序、BDD/TDD 门禁、UI 合同和完成证据。
- Slice 路线：逐个展示“做什么、会看到什么、完成标准”。
- 角色闭环：学生、教师、导师和 Owner 的最终工作路径。
- 最终蓝图：页面、数据、权限、质量和交付状态。

## 交互

- 左侧目录在桌面端固定，移动端变成顶部横向目录。
- Slice 使用可点击展开区，默认展开当前最近任务 Slice 1。
- 角色使用标签切换，展示对应工作路径和可见功能。
- 提供“展开全部”和“收起全部”。

## 视觉

沿用已批准的工作台视觉合同：深蓝、青绿色、白色和少量橙色；Microsoft YaHei UI；4px/8px 圆角；紧凑、清晰、非营销页。页面不显示开发者内部废话，不复制案例网站 UI。

## 验收

- Microsoft Edge 控制台无错误。
- 1440px 和 375px 均无横向溢出或文字重叠。
- 所有按钮可用键盘操作并有可见焦点。
- 内容与当前总控 Skill、UI 合同、完成矩阵和 Slice 1-6 一致。
- 文件可直接从桌面打开，不依赖开发服务器。
