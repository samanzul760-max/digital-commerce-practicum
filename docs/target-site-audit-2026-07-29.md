说明：本报告按 138 个 `SB-*` 能力建立全量审计范围，不记录账号、密码、Cookie、token 或私有接口。项目状态以当前源码、服务端 API、Playwright 测试和本轮验证结果为准。逐项矩阵见 [138 项 SB 全量矩阵](target-site-sb-full-matrix-2026-07-29.md)。

本轮追加证据（2026-07-29）：已在本机浏览器完成目标站账号认证；认证后目标站停在组织列表中间页，未返回计划管理页，故本轮没有重新执行目标站内的创建、发布、删除、上传、审批或导出。下面的目标站功能范围保留已有审计工件的观察结论；本轮新鲜的可执行证据仅覆盖登录/组织入口状态以及本地项目的 typecheck、build 和 17 条相关 Playwright 回归。未获得本轮浏览器或 API 证据的本地能力不能因此升级为 `PASS`。

## 一、目标站实测功能面

### 管理端

- 作业管理：创建作业、时间筛选、状态筛选、列表/空状态。
- 教学计划：计划列表、创建入口、计划管理、前往教学；目标路由还包含计划详情、计划数据、成员数据等入口。
- 资源管理：添加资源；按可见范围、资源类型筛选；分页；查看、移除；当前实测 31 条资源，包含训练营、课程、任务。
- 成员管理：申请列表、添加虚拟组、全部成员、邀请链接、分页、角色显示、管理、移除；当前实测 31 人，包含管理员、教师、学生。
- 实训室设置：组织归属、名称、头像、封面、简介、定位、模板、创建时间、教学/自学模式、私密/组织公开/平台公开、复制、删除、保存。
- 落地页管理：实训室介绍富文本、段落、字体/字号、字数、营销位图片或视频、保存。
- 批阅中心：计划批阅、课堂作业批阅、待批阅/已批阅、按计划进入批阅。
- 数据中心：总完成率、完成人数、实训室人数、未参与人数、计划完成情况、实时播报、总得分排行榜、一键导出、计划数据/成员数据入口。
- 条件入口：比赛、创业计划、任务、课程、证书等；未配置时显示选择分类/课程/证书或暂无数据。

### 学生端

- 首页：加入人数、资源数、计划数、计划/课程/软件快捷入口、进行中的计划。
- 学习计划：计划列表、计划详情、活动状态；本次目标站直接访问计划详情出现 500，属于目标站现状问题。
- 待办中心：作业列表和空状态。
- 资源中心/我的应用：软件、训练营、任务、课程分类。
- 我的数据：计划进度、实训完成率、得分、完成数、计划对比、技能掌握图谱、优势/劣势能力。

## 三、当前最明确的未达到项

1. **服务端化学习进度**：这是最根本的差距。学生做了什么、做到哪一步、是否完成，目前不能可靠地跨账号、跨浏览器恢复。
2. **成员管理真实闭环**：虚拟组、邀请链接、申请审批、批量处理、角色变更审计尚未形成服务端工作流。
3. **教师工作台**：已有作业 API，但缺教师可用的创建、发布、课堂执行、公告、学生可见范围与结果查看页面。
4. **计划编辑器完整迁移**：目录节点 API 已有，但页面仍混用本地 store；目标站的活动来源选择、批量导入、自定义活动附件、资源、预览、发布撤回尚未全链路完成。
5. **实训室设置和落地页**：当前更接近元数据原型，文件/媒体和公开范围的持久化、预览、失败重试缺失。
6. **数据中心真实分析**：当前有统计展示，但还没有可审计的时间筛选、下钻、成员详情、技能图谱和真实导出。
7. **完整功能矩阵已展开但尚未对齐**：目标功能清单的 138 个 `SB-*` 能力已经逐项展开；当前判定为 `PARTIAL 77`、`MOCK 16`、`IMPLEMENTED_UNVERIFIED 1`、`MISSING 44`，没有任何项目能力达到本审计规则下的 `PASS`。

## 四、建议补齐顺序

### P0：先形成真实业务闭环

1. 统一当前组织/实训室过滤，补服务端数据隔离和角色矩阵。
2. 将学习位置、活动进度、通知和提交草稿迁移到服务端，补刷新、越权、重复提交测试。
3. 完成计划编辑器页面迁移，并接入活动导入、发布/撤回/归档和版本冲突。
4. 完成教师作业/公告/批阅工作台，让“计划发布 -> 学生执行 -> 提交 -> 教师批阅 -> 学生再提交”跑通。

### P1：补管理效率和可观察性

1. 成员虚拟组、邀请、申请审批、批量处理和审计日志。
2. 资源详情、批量导入、发布可见性、上传校验和失败重试。
3. 数据中心筛选、下钻、成员详情、技能图谱和真实导出。
4. 实训室落地页媒体、公开范围、复制/删除恢复和学生端预览。
